---
name: Airline classification evidence
description: Source and coverage rules for airline comparison categories.
---

Use airline classification metadata only when each supplied classification has a reliable source link and a verification status. Supported categories include region, business model, airline type, airline size, ownership, and airline group. Do not estimate missing or uncertain values. Mark them Unclassified or Needs Review, keep those airlines available for manual comparison, and exclude them from classification-specific benchmarks until verified. Hide filters when no verified values exist, and show coverage and benchmark sample sizes.

**Why:** The user explicitly requested source-backed classifications and transparent benchmark coverage.

**How to apply:** Store classification labels separately from financial values with source references and verification status; enable a filter only when its verified category values are present.
